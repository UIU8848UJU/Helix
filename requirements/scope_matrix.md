# Scope Matrix — 浏览器 MCP

## In Scope(一期)
- 通过 MCP 打开指定 URL(浏览器导航)
- 读取页面内容(文本/结构)
- 识别并列出按钮,返回信息:text、selector、位置/尺寸、可见性/可点击性、aria/role/disabled
- 点击按钮/元素(点击交互)
- 登录态:storageState 保存/加载
- 多页面导航(打开/后退/前进/等待加载)
- 页面读取与按钮提取分工具组织

## In Scope(二期)
- 表单填充(向 input/select/textarea 提交信息)
- 上传文件(向表单 input[type=file] 注入本地文件)
- 下载文件(监听 download 事件,保存到受控目录)
- 文件衔接:受控目录 + 文件工具(读文件/列目录/拿路径)
- 复杂交互(iframe 内表单、动态表单、shadow DOM 等)

## Out of Scope(一期明确不做)
- 远端浏览器/CDP 驱动(二期/三期 ARCH-001 预留)
- 自动登录/凭据注入(凭据不经 AI,由 storageState 承载)
- 浏览器图形界面控制(非 UI 自动化录屏)
- 反爬绕过、验证码自动破解(合规边界)
- 定时任务调度(可用外部 Agent 循环)
- Windows 桌面/原生应用自动化(只做网页)
- 表单/上传/下载(一期不做,移入二期)

## Future Scope(二期及以后)
- RemoteDriver:通过 CDP 连接远端浏览器,复用 ssh-mcp 主机
- 容器化浏览器服务(多实例隔离)
- 复用 credential-broker 注入登录凭据(需安全评审)
- 会话/多标签隔离模型完善
- 更丰富的页面结构分析(iframe、shadow DOM 穿透等)

## 边界责任
| 边界 | 本系统 | 外部 |
|------|--------|------|
| 页面访问合规 | 只做用户授权访问的站点;不做反爬/绕过 | 目标站点策略 |
| 凭据安全 | 存储 storageState,不经 AI/日志 | 用户首次登录 |
| 文件安全 | 受控目录、限制路径 | 目标站点的上传/下载规则 |
| 浏览器生命周期 | MCP 管理浏览器进程 | — |
