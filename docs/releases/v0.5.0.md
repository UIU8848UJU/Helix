# Helix v0.5.0

面向 AI Agent 的远程执行 Runtime 0.5.0 版本。本次发布集中在**输出解码、密钥认证，以及可观测/可取消的原子 SFTP 传输**。

## 亮点

- **协议 v7**：新增 `task_watch` 与字节进度；`identity_file` 覆盖所有操作；能力集增加 `identity_file_v1` 与 `task_watch_v1`。
- **原子传输**：写 `<target>.helix.part.<taskId>` 后通过 `posix-rename@openssh.com` 落位；无扩展时回退 unlink+rename；失败路径统一清理 `.part`。
- **进度与取消**：任务池 `done/total/version` 原子量；首次上报必唤醒 watcher，之后 100ms 节流；取消/超时只删除 `.part`，目标文件不受影响。
- **密钥认证**：daemon 支持 `userauth_pubkey_file`，`auth.rs` 在连接前给出 `IDENTITY_FILE_MISSING/UNREADABLE/ENCRYPTED` 等结构化错误。
- **输出解码**：Rust/TS 双解码器修复 OEM 代码页造成的 BOM 损坏（`EF BB BF → EF BB 3F`），同时保留真 GBK 流。
- **新 MCP 工具**：`task_status`、`task_watch`、`task_cancel`；`ssh_upload/ssh_download` 支持 `detach`（仅 broker 主机）。
- **稳定错误码**：`CREDENTIAL_MISSING`、`AUTH_FAILED`、`TRANSFER_CANCELLED`、`TRANSFER_TIMEOUT`。

## 升级注意

- **daemon 与 MCP bundle 必须一起升级**：协议从 v5 升到 v7，旧客户端会拒绝新 daemon（`expected 5, got 7`）。
- 更新后需要重启 MCP 客户端（Claude Code / Codex）加载新 bundle。
- 密钥认证：本构建的 libssh2 不支持 ed25519，请使用 RSA 密钥（系统 `ssh` 可用不代表 libssh2 可用）。
- 符号链接在传输中统一拒绝，避免目录总进度与实际上传字节不一致。

## 已知限制

- 无 `posix-rename` 扩展的服务器会走非原子回退路径。
- Windows 本地替换在 rename 失败时才删除目标，非严格原子；Windows 真机 E2E 目前不在 CI 中。
- 255 字节文件名叠加 `.part` 后缀可能超过 `NAME_MAX`。
